온라인 연결 준비

기존 Firebase 프로젝트에 연결해. 설정은 이 기기에 저장되며 다른 참가자는 각자 한 번 설정할 필요 없이 같은 앱 설정을 사용해야 해.

프로젝트 ID와 데이터베이스 주소는 이미 입력되어 있어. Firebase 웹 앱 설정 전체를 한 번만 붙여 넣으면 이후에는 자동 연결돼.

Firebase Console → 프로젝트 설정 → 내 앱 → SDK 설정 및 구성에서 웹 앱 설정을 복사할 수 있어. API Key와 App ID는 데이터베이스 주소만으로 계산할 수 없어.
